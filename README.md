# Dinkov Distilled: The Metabolic Theory Of Health

This repository contains the curated booklet of Markdown files detailing the bioenergetic metabolic theory of health.

## Deployment

The live site is deployed and accessible at:
👉 **[https://dinkov-distilled.vercel.app/](https://dinkov-distilled.vercel.app/)**

## Key Content Areas
- **Foundations of Bioenergetic Health:** Core philosophies, mitochondrial respiration, and redox dynamics.
- **Hormonal Control Systems:** Insights into thyroid conducting systems, adrenal axes, and anti-metabolic stressors.
- **Practical Protocols:** Detailed dietary frameworks, therapeutic supplements, and diagnostics.
- **Animal Metabolic Models:** Evolutionary biology lessons from bears, squirrels, pigs, and echidnas.

## Development & Utilities
- `c.sh`: Concatenation script to package project files for analysis.
- `apply_changes.py`: Robust SEARCH/REPLACE utility to safely integrate updates.
- `clean_filenames.py`: Sanitation tool for internal markdown links and filenames.
